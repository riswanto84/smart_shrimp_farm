# Perbaikan Status Ollama di Dashboard

- Card Status AI dihapus dari grid KPI dashboard.
- Status Ollama dipindahkan ke topbar kanan, sejajar dengan cuaca, tanggal, dan notifikasi.
- Tampilan berupa indikator ringkas, bukan card.
- Status Online, Timeout, Model belum tersedia, dan Offline tetap ditampilkan.
- Tombol cek ulang dipertahankan dalam bentuk ikon refresh.
- Pemeriksaan otomatis setiap 30 detik tetap berjalan.
- Tampilan responsif untuk desktop dan perangkat seluler.
- Tidak ada perubahan model atau migration database.
