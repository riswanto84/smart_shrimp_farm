# Penambahan Card Laba/Rugi Dashboard

Perubahan:

- Menambahkan card **Laba / Rugi** pada ringkasan utama Dashboard.
- Rumus: `Total Omzet - Total Pengeluaran` pada siklus yang dipilih.
- Menampilkan status **Laba**, **Rugi**, atau **Impas**.
- Menampilkan margin laba/rugi terhadap omzet.
- Warna indikator berubah otomatis: hijau untuk laba, merah untuk rugi, dan emas untuk impas.
- Tidak ada perubahan model maupun migration database.
