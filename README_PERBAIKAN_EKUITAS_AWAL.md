# Perbaikan Ekuitas Awal

Masalah:
Modal Pemilik sebelumnya dihitung dengan mengurangkan laba/rugi tahun berjalan.
Ketika laba berjalan negatif, nilai modal justru meningkat secara tidak wajar.

Rumus lama:
Modal = Aset Awal - Kewajiban Awal - Laba/Rugi Berjalan - Ekuitas Awal Lain

Rumus baru:
Modal Pemilik = Aset Awal - Kewajiban Awal - Ekuitas Awal Lain

Laba/rugi tahun berjalan tetap ditampilkan sebagai informasi dan tetap
memengaruhi laporan neraca berjalan, tetapi tidak digunakan dalam rekonsiliasi
Modal Pemilik pada menu Saldo Awal.

Tidak ada perubahan model dan tidak memerlukan migration.
