# Perbaikan Payroll

- Slip gaji dapat dilihat dan dicetak dari browser.
- Slip gaji tersedia sebagai PDF melalui endpoint khusus ReportLab.
- Tombol WhatsApp membuat pesan berisi ringkasan gaji dan tautan PDF.
- Nomor HP karyawan dinormalisasi ke kode negara Indonesia 62.
- Gaji Pokok dan Upah Harian pada Tambah/Edit Karyawan otomatis berformat ribuan.
- Integrasi pengeluaran payroll selalu mengisi payment_status=paid.

Tidak ada migration database baru pada paket ini.
