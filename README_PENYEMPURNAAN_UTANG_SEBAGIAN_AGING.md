# Penyempurnaan Utang Usaha

Fitur pembayaran sebagian yang sudah ada dipertahankan dan disempurnakan.

## Perubahan
- Status otomatis: Belum Dibayar, Dibayar Sebagian, Lunas.
- Filter khusus Dibayar Sebagian dan Belum Dibayar.
- Progress pelunasan per dokumen dan keseluruhan.
- Ringkasan dokumen belum dibayar dan dibayar sebagian.
- Jatuh tempo 7 hari dan bulan berjalan.
- Aging report: belum jatuh tempo, 1–30, 31–60, 61–90, dan lebih dari 90 hari.
- Detail utang menampilkan progress pelunasan.
- Tidak ada model atau migration baru; riwayat pembayaran lama tetap dipakai.
