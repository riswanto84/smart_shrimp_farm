# Informasi Panen Parsial pada Dashboard

Perbaikan menambahkan ringkasan panen parsial pada panel **Realisasi Panen Riil** di Dashboard:

- Total berat panen parsial dalam kg dan ton.
- Jumlah/frekuensi panen parsial.
- Jumlah kolam yang pernah dipanen parsial.
- Tabel rekap per kolam: frekuensi, total berat parsial, tanggal parsial terakhir, dan size terakhir.
- Panen total/final tidak dicampur ke angka panen parsial.
- Seluruh data mengikuti siklus budidaya yang sedang dipilih.

Tidak ada perubahan model maupun migration database.
