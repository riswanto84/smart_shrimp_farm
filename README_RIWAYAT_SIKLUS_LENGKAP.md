# Fitur Riwayat Siklus Lengkap

Fitur baru tersedia di menu **Siklus > Riwayat Siklus**.

## Fitur
- Ringkasan seluruh siklus selesai: produksi, omzet, laba/rugi, FCR, SR Index, dan ROI.
- Daftar seluruh siklus aktif maupun selesai.
- Detail historis per siklus dan rekap per kolam.
- Komposisi biaya per siklus.
- Perbandingan KPI antar siklus selesai.
- Ekspor Excel dua sheet: Ringkasan Siklus dan Per Kolam.
- Laporan akhir PDF tetap tersedia untuk siklus selesai.
- Data lama tidak dihapus saat siklus ditutup; setiap transaksi tetap terikat ke siklus asal.

Tidak ada migration database baru karena fitur menggunakan relasi cycle dan final_snapshot yang sudah tersedia.
