# Perbaikan Dashboard Biomassa Aktif Tersisa FR dan Index

Perubahan:

1. Panel Biomassa Aktif Tersisa pada dashboard dipisahkan menjadi dua panel:
   - Biomassa Aktif Tersisa — FR
   - Biomassa Aktif Tersisa — Index
2. Masing-masing panel menampilkan:
   - total biomassa tersisa dalam ton;
   - diagram donat;
   - rincian biomassa tersisa per kolam.
3. Kedua metode sama-sama mengurangi panen parsial dan biomassa mortalitas yang terjadi setelah sampling terakhir.
4. Kolam yang telah selesai/panen total tetap dikecualikan dari kedua estimasi biomassa aktif.
5. Tidak ada perubahan model dan tidak memerlukan migration baru.
