# Perbaikan Tampilan Dashboard Proporsional

Perubahan pada `templates/core/dashboard.html`:

- Card Biomassa Aktif Tersisa FR dan Index dibuat penuh sampai sisi kanan area dashboard.
- Isi card biomassa disusun proporsional: donut di kiri dan daftar kolam dua kolom di kanan.
- Ringkasan kolam, grafik panen, riwayat panen, estimasi DOC 120, dan aktivitas terbaru menggunakan lebar penuh.
- Parameter terbaru dan grafik suhu tetap berdampingan pada desktop dengan rasio yang lebih seimbang.
- Estimasi DOC 120 memiliki tiga card dengan lebar sama.
- Responsif untuk laptop, tablet, dan ponsel; daftar biomassa berubah menjadi satu kolom pada layar kecil.
- Tidak ada perubahan model atau migration database.
