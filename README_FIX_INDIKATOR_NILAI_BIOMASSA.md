# Perbaikan indikator Nilai Biomassa Aktif

Indikator tidak lagi memakai nominal rupiah absolut atau otomatis menjadi kritis karena salah satu parameter kolam merah.

Kesehatan finansial memakai Coverage Biomassa:
- Sehat: >= 2,00x kewajiban
- Waspada: >= 1,00x dan < 2,00x
- Kritis: < 1,00x
- Belum dapat dinilai: kewajiban nol/tidak tersedia

Kualitas data kolam ditampilkan terpisah sebagai Data memadai, Perlu dipantau, Perlu validasi, atau Belum ada data.
