# Format angka Indonesia

Perbaikan ini menambahkan formatter terpusat pada `core/templatetags/currency.py`:

- `angka0`: bilangan bulat dengan titik ribuan
- `angka1`: satu angka desimal
- `angka2`: dua angka desimal
- `angka3`: tiga angka desimal
- `persen`: angka persentase format Indonesia
- `rupiah`: nominal Rupiah format Indonesia

Halaman Riwayat Siklus, Detail Riwayat Siklus, laporan PDF, dan ekspor Excel telah disesuaikan.
