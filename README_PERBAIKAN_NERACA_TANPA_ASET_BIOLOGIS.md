# Perbaikan Neraca Tanpa Aset Biologis

- Aset Biologis di Kolam dihapus dari tampilan Neraca.
- Biomassa udang tidak lagi masuk Total Aset, komposisi aset, ekuitas, rasio neraca, atau PDF Neraca.
- Estimasi Laba Akhir Siklus tetap menggunakan Biomassa Index untuk proyeksi bisnis dan tidak mengubah neraca akuntansi.
- Indikator Kritis pada kartu kolam tidak lagi ditampilkan di Neraca. Sebelumnya indikator berubah menjadi Kritis jika salah satu metrik merah; SR juga dihitung dari populasi tersisa setelah panen dibanding tebar sehingga dapat menimbulkan label yang menyesatkan.
